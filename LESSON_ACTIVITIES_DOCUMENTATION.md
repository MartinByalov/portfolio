# Документация на компонентите и интерактивните дейности в платформата
## (Lesson Activities & Interactive Components Documentation)

Този документ описва архитектурата, предназначението, параметрите и пълните JSON схеми на всички компоненти и дейности, които се използват за създаване на интерактивни уроци и упражнения в учебната платформа по Информационни технологии.

---

## I. Мултимедия и теоретично съдържание (6 основни компонента)

### 1. `text` (Текстов блок / Теория)
* **Предназначение:** Представяне на основния теоретичен материал, дефиниции, насоки и практически примери.
* **Поддържано форматиране:** Поддържа Markdown синтаксис:
  - `### Заглавие` &rarr; рендира се като тематично подзаглавие `<h4 class="wb-task-heading">`
  - `**текст**` &rarr; получер (bold) текст `<strong>`
  - `*текст*` &rarr; курсив (italic) текст `<em>`
  - Автоматично разделяне на абзаци (`<p>`) и пренасяне на редове (`<br>`)
  - Директна поддръжка на валидни HTML елементи: `<ul>`, `<ol>`, `<li>`, `<table>`, `<blockquote>`, `<code>`, `<mark>`.
* **JSON схема:**
```json
{
  "type": "text",
  "id": "intro-theory-block",
  "content": "**Ефективното търсене на информация** означава бързо и точно откриване на нужните източници чрез подходящи ключови думи и филтри.<br><br>• **Локално търсене:** във файловата система чрез File Explorer.<br>• **Интернет търсене:** чрез търсещи машини."
}
```

### 2. `image-with-instruction` (Изображение с инструкции)
* **Предназначение:** Показва визуално табло с ясни указания към ученика/учителя, път към файл в `assets/...`, конкретни изисквания към екранната снимка и вграден елегантен интерактивен fallback макет, ако изображението още не е качено на сървъра.
* **Свойства:**
  - `id` (string): Уникален идентификатор (използва се и за определяне на fallback илюстрацията).
  - `title` (string): Заглавие на инструкцията/изображението.
  - `src` (string): Относителен път до файла (напр. `assets/it-8-5/concept-map.jpg`).
  - `instruction` (string): Подробен текст какво трябва да се визуализира или направи.
  - `fallbackMockup` (string, optional): Тип на визуалната схема или илюстрация.
* **JSON схема:**
```json
{
  "type": "image-with-instruction",
  "id": "img-search-filters-guide",
  "title": "Инструкция: Настройки на разширени филтри",
  "src": "assets/it-8-5/fileExplorerFilter.png",
  "instruction": "Отворете File Explorer, кликнете в полето Search и изберете филтрите за дата (Date modified) и размер (Size)."
}
```

### 3. `image-gallery` (Галерия от изображения)
* **Предназначение:** Организиране на две или повече свързани изображения в адаптивна решетка със заглавия и подписи (например съпоставка на интерфейси).
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие на галерията.
  - `items` (array): Масив от обекти с `src`, `alt`, `title`.
* **JSON схема:**
```json
{
  "type": "image-gallery",
  "id": "search-comparison-gallery",
  "title": "Taskbar Search срещу File Explorer",
  "items": [
    {
      "src": "assets/it-8-5/win11_search_ui.jpg",
      "alt": "Taskbar Search интерфейс",
      "title": "Search от лентата със задачи"
    },
    {
      "src": "assets/it-8-5/fileExplorer.png",
      "alt": "File Explorer интерфейс",
      "title": "Търсене във File Explorer"
    }
  ]
}
```

### 4. `video` (Видео блок)
* **Предназначение:** Вграждане на обучително видео с контролна лента, постер, възможност за повторение и опционален транскрипт или описание.
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие на видеото.
  - `src` (string): Път към видео файла (MP4/WebM) или външен видео източник.
  - `poster` (string, optional): Изображение за корица преди стартиране.
  - `description` (string): Кратко резюме на видео урока.
* **JSON схема:**
```json
{
  "type": "video",
  "id": "video-network-collab",
  "title": "Видео урок: Съвместна работа в Google Документи",
  "src": "assets/it-8-3/collab-demo.mp4",
  "poster": "assets/it-8-3/video-poster.jpg",
  "description": "Кратка демонстрация на споделяне на документ, задаване на права за редактиране и следене на история на версиите."
}
```

### 5. `ui-mockup` (Интерактивен макет на интерфейс)
* **Предназначение:** Реалистичен визуален модел на интерфейс на софтуерно приложение (напр. пощенска кутия, прозорец на браузър, настройки за споделяне в Google Drive) за демонстрация на работната среда без риск от объркване.
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие на макета.
  - `mockupType` (string): Тип на макета (напр. `browser`, `file-explorer`, `email-client`, `cloud-drive`).
  - `elements` (array): Списък от интерактивни бутони, зони или полета в макета.
* **JSON схема:**
```json
{
  "type": "ui-mockup",
  "id": "mockup-cloud-sharing",
  "title": "Макет на прозорец за споделяне в облачно пространство",
  "mockupType": "cloud-drive",
  "elements": [
    { "name": "Поле за имейл", "role": "Добавяне на съученици по имейл адрес" },
    { "name": "Падащо меню за права", "role": "Избор: Читател / Коментатор / Редактор" },
    { "name": "Бутон Копиране на връзка", "role": "Генерира споделен линк" }
  ]
}
```

## II. Интерактивни визуализации и симулатори (6 компонента)

### 7. `visualization` (Интерактивна схема / Поток)
* **Предназначение:** Схематично визуализиране на последователни стъпки, архитектури или връзки с плавна анимация на поява.
* **Свойства:**
  - `layout`: `"flow"` (последователен със стрелки) или `"split"` (разделен в колони).
  - `nodes`: Масив от обекти с `label`, `description`, опционално `image`.
* **JSON схема:**
```json
{
  "type": "visualization",
  "id": "flow-search-process",
  "title": "Етапи на ефективното търсене",
  "flow": "От формулиране на заявка до критична оценка",
  "layout": "flow",
  "nodes": [
    { "label": "1. Формулиране", "description": "Определяне на ключови думи и цел" },
    { "label": "2. Филтриране", "description": "Прилагане на оператори и разширения" },
    { "label": "3. Оценка", "description": "Проверка на автор, дата и надеждност" }
  ]
}
```

### 8. `wildcard-visualizer` (Симулатор на глобални символи `*` и `?`)
* **Предназначение:** Интерактивно изследване на действието на глобалните символи (wildcards). Ученикът въвежда или избира шаблон (`*.docx`, `photo?.jpg`, `*2026.xlsx`) и в реално време вижда кои файлове от списъка се мачват (зелено) и кои се отхвърлят (червено).
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие.
  - `presetPatterns` (array): Готови шаблони за бърз избор.
  - `files` (array): Списък от тестови имена на файлове с атрибути.
* **JSON схема:**
```json
{
  "type": "wildcard-visualizer",
  "id": "network-wildcard-tester",
  "title": "Интерактивен симулатор на глобални символи (* и ?)",
  "presetPatterns": ["lesson*.pdf", "*2026.xlsx", "Report_?.pdf", "*cam?.*", "Task-??.*"],
  "files": [
    "lesson1.pdf", "lesson_it_8.pdf", "test_lesson.pdf",
    "budget2026.xlsx", "data2026_final.xlsx", "2026_report.xlsx",
    "Report_3.pdf", "Report_12.pdf", "Report_май.pdf",
    "camera.docx", "acam1.xlsx", "webcam.pptx", "campus.pdf",
    "Task-A1.docx", "Task-12.pptx", "Task-ABC.txt"
  ]
}
```

### 9. `venn-logic-diagram` (Диаграма на Вен за логически оператори)
* **Предназначение:** Графично и логическо визуализиране на булевите оператори (`AND`, `OR`, `NOT`). При кликване върху оператор съответните области от кръговете светват в интерактивен цвят с обяснение.
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие на компонента.
  - `operators` (array): Масив от оператори с `name`, `query`, `effect`, `activeRegion` (`"intersection"`, `"union"`, `"left-only"`), `color`.
* **JSON схема:**
```json
{
  "type": "venn-logic-diagram",
  "id": "search-venn-diagram",
  "title": "Логически оператори (AND, OR, NOT) в действие",
  "operators": [
    {
      "name": "AND",
      "query": "мрежи AND сигурност",
      "effect": "Намира само ресурси, съдържащи ЕДНОВРЕМЕННО и двете понятия.",
      "activeRegion": "intersection",
      "color": "#3B82F6"
    },
    {
      "name": "OR",
      "query": "компютър OR лаптоп",
      "effect": "Намира резултати, съдържащи поне едно от двете понятия.",
      "activeRegion": "union",
      "color": "#10B981"
    },
    {
      "name": "NOT",
      "query": "облак NOT прогноза",
      "effect": "Намира 'облак', но изключва всички страници за метеорология.",
      "activeRegion": "left-only",
      "color": "#EF4444"
    }
  ]
}
```

### 10. `before-after-slider` (Плъзгач „Преди и След“)
* **Предназначение:** Интерактивно сравнение между два резултата чрез плъзгач или превключвател (например резултати от обикновено търсене спрямо точна фраза с кавички или филтриране с минус).
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие.
  - `beforeLabel` & `beforeDescription`: Състояние Преди.
  - `afterLabel` & `afterDescription`: Състояние След.
* **JSON схема:**
```json
{
  "type": "before-after-slider",
  "id": "filter-comparison-slider",
  "title": "Филтриране на хобита: Без минус срещу С минус (-)",
  "beforeLabel": "Без филтър: \"нови игри\"",
  "beforeDescription": "Резултатите са залети от мобилни игри за Android и iOS, реклами за смартфони и микротрансакции.",
  "afterLabel": "С филтър: \"нови игри\" -мобилни OR конзола",
  "afterDescription": "Всички мобилни сайтове са изолирани; показват се само заглавия за компютър или игрови конзоли."
}
```

### 11. `query-builder` (Конструктор на заявки)
* **Предназначение:** Учениците сглобяват правилна съставна заявка за търсене, като избират или подреждат градивни блокове. При правилна комбинация се активира визуално потвърждение.
* **Свойства:**
  - `id` (string): Идентификатор.
  - `title` (string): Заглавие на задачата.
  - `availableBlocks` (array): Налични блокчета за кликване.
  - `targetPattern` (array): Идентификатори на верните блокчета в точния ред.
  - `successMessage` (string): Съобщение при успех.
* **JSON схема:**
```json
{
  "type": "query-builder",
  "id": "school-doc-query-builder",
  "title": "Конструирайте заявката: Официален правилник на училището",
  "availableBlocks": [
    { "id": "b1", "text": "filetype:pdf" },
    { "id": "b2", "text": "site:spgke.com" },
    { "id": "b3", "text": "\"правилник за вътрешния ред\"" },
    { "id": "b4", "text": "-училище" }
  ],
  "targetPattern": ["b1", "b2", "b3"],
  "successMessage": "Отлично! Сглобихте перфектната заявка: filetype:pdf site:spgke.com \"правилник за вътрешния ред\""
}
```

### 12. `live-search-sandbox` (Симулатор на търсачка в реално време)
* **Предназначение:** Пълнофункционален симулатор на търсеща машина с база данни, който разпознава оператори `site:`, `filetype:`, `-`, кавички `""` и ключови думи, като филтрира резултатите в реално време.

```json
{

  "placeholder": "Опитайте: \"отворен код\" filetype:pdf, site:spgke.com...",

    {

      "url": "https://spgke.com/docs/pravilnik.pdf",
      "snippet": "Официален училищен правилник за учебната година в PDF формат.",
      "tags": ["site:spgke.com", "filetype:pdf", "правилник за вътрешния ред"]
    },
    {
      "title": "Creative Commons и Отворен код в образованието",
      "url": "https://opensource.bg/edu/guide.docx",
      "snippet": "Ръководство за свободно споделяне на ресурси под Creative Commons лиценз.",
      "tags": ["отворен код", "filetype:docx", "Creative Commons"]
    }
  ]
}
```

## III. Интерактивни упражнения и практически задачи (6 компонента)

### 13. `interactive-matching` (Свързване на понятия)
* **Предназначение:** Свързване на термини с техните дефиниции.
* **Режими:**
  - **Класически режим:** Двуколонно избиране чрез падащи списъци.
  - **Разпилени карти (`mode: "scattered"` / LearningApps стил):** Интерактивни плаващи карти, които се влачат или кликват една върху друга за образуване на двойка.
* **JSON схема:**
```json
{
  "type": "interactive-matching",
  "id": "match-network-services",
  "title": "Свържете услугата с нейното точно описание",
  "mode": "scattered",
  "pairs": [
    { "concept": "Блог", "definition": "Онлайн дневник с хронологично подредени публикации" },
    { "concept": "LMS", "definition": "Софтуерна среда за организиране и управление на електронно обучение" },
    { "concept": "Cloud Storage", "definition": "Виртуално пространство за съхранение и споделяне на файлове" },
    { "concept": "Чат", "definition": "Услуга за бърз обмен на текстови съобщения в реално време" }
  ]
}
```

```json
    }
```

### 15. `category-sorter` (Разпределяне по категории)
* **Предназначение:** Разпределяне на списък от термини, команди или разширения в предварително зададени категории (напр. Типове файлове, Мрежови роли, Оператори за търсене).
* **Свойства:**
  - `categories` (array): Категории с `id` и `name`.
  - `items` (array): Елементи с `text` и `categoryId`.
* **JSON схема:**
```json
{
  "type": "category-sorter",

  "title": "Разпределете инструментите според тяхната среда на приложение",
  "categories": [
    { "id": "cat-web", "name": "Интернет търсещи машини" },

    { "id": "cat-cloud", "name": "Облачни услуги и права" }
```

### 16. `spot-the-bug` (Открий грешката / Анализ на казус)
* **Предназначение:** Учениците анализират конкретен сценарий (напр. нарушена сигурност, некоректна заявка или грешка при споделяне) и откриват скритите проблеми чрез интерактивни карти.
* **Свойства:**
  - `scenarioDescription` (string): Описание на ситуацията.
  - `bugsToFind` (array): Списък от казуси с `bugTitle` и `explanation`.
* **JSON схема:**
```json
{
  "type": "spot-the-bug",
  "id": "spot-bug-security",
  "title": "Открийте грешките в сигурността на профила",
  "scenarioDescription": "Ученик споделя паролата си с приятел и приема покани от непознати в социална мрежа.",
  "bugsToFind": [
    {
      "bugTitle": "Споделяне на паролата с приятел",
      "explanation": "Грешка! Паролата е строго лична и никога не се споделя с никого, дори с най-близки приятели."
    },
    {
      "bugTitle": "Приемане на всички покани за приятелство",
      "explanation": "Грешка! Профили на непознати лица могат да бъдат фалшиви или създадени с цел кибертормоз и фишинг."
    }
  ]
}
```

### 17. `interactive-checklist` (Интерактивен чек-лист)
* **Предназначение:** Практически списък за проверка на изпълнението на учебна задача или самооценка по критерии със запазване на прогреса.
* **Свойства:**
  - `id` (string): Идентификатор.
  - `bare` (boolean): Ако е `true`, се визуализира компактно вътре в карта/акордеон.
  - `checkItems` (array): Списък с текстови критерии за отмятане.
* **JSON схема:**
```json
{
  "type": "interactive-checklist",
  "id": "checklist-diploma-task",
  "bare": true,
  "checkItems": [
    "Намерени ли са изображения с прозрачен фон (PNG) на ракета и топка?",
    "Зададена ли е пейзажна ориентация на страницата (Landscape)?",
    "Изображението на тенис корта позиционирано ли е зад текста (Behind Text)?",
    "Добавен ли е артистичен надпис с WordArt?",
    "Вмъкнати ли са икони на социални мрежи в долната част на дипломата?"
  ]
}
```

### 18. `exercise-modal` (Модален прозорец за упражнение)
* **Предназначение:** Изскачащ прозорец с детайлно практическо задание, ресурси за изтегляне, инструкции стъпка по стъпка и линкове. Отваря се чрез елемент `type: "tag"`.
* **Свойства:**
  - `id` (string): Съвпада с `modalTarget` на активиращия таг.
  - `title` (string): Заглавие на прозореца.
  - `instructions` (string / HTML): Форматиран текст с указания.
  - `resources` (array): Масив от външни материали с `label`, `href`, `icon`.
* **JSON схема:**
```json
{
  "type": "exercise-modal",
  "id": "modalDiplomaExercise",
  "title": "Практическа задача: Изработване на спортна диплома",
  "instructions": "<div class='exercise-instructions'><ol><li>Намерете изображения с прозрачен фон за тенис корт, ракета и топка.</li><li>Създайте нов Word документ в Landscape формат.</li><li>Оформете заглавието с WordArt и добавете блок 'Последвайте ни'.</li></ol></div>",
  "resources": [
    {
      "icon": "fa-solid fa-folder-open",
      "label": "Материали за тенис диплома",
      "href": "https://bg.izzi.digital/DOS/309985/505522.html"
    }
  ]
}
```

## IV. Формиращо оценяване, рефлексия и речник (3 компонента)

### 19. `quiz` (Тест за самопроверка)
* **Предназначение:** Тестови въпроси с единичен или множествен избор, интерактивна проверка, брой точки и детайлни педагогически обяснения към верния отговор.
* **JSON схема:**
```json
{
  "type": "quiz",
  "id": "quiz-networks-review",
  "title": "Тренировъчен тест: Компютърни мрежи и услуги",
  "questions": [
    {
      "question": "При търсене в име на файл глобалният символ (*) замества:",
      "options": [
        "точно един знак",
        "произволен брой знаци (0, 1 или повече)",
        "само цифри",
        "само разширението на файла"
      ],
      "correctIndex": 1,
      "explanation": "Вярно: Звездичката (*) замества произволен брой знаци, докато въпросителният знак (?) замества точно един знак."
    }
  ]
}
```

### 20. `emotiometer` / `mood-animal-generator` (Емоциометър и Рефлексия)
* **Предназначение:** Крайна рефлексия след урока. Ученикът оценява своето разбиране, ниво на енергия и увереност за предстоящото изпитване.
* **JSON схема:**
```json
{
  "type": "emotiometer",
  "id": "reflection-emotiometer-1-5",
  "title": "Как се чувствате след обобщителното упражнение?"
}
```

### 21. `glossary-list` (Интерактивен речник)
* **Предназначение:** Систематизиран списък с терминологични дефиниции на новите понятия от урока с опционални подкани за визуално генериране.

```json
      "term": "LMS (Learning Management System)",
      "definition": "Софтуерна платформа за организиране, управление и проследяване на електронното обучение."
    }
  ]
}
```

## V. Навигационни и структурни елементи (3 компонента)

### 22. `tag` (Цветни етикети / Значки)
* **Предназначение:** Компактни интерактивни бутони или визуални баджове, разделящи учебното съдържание. При клик отварят съответния `exercise-modal`.
* **Основни варианти и тонове:**
  - `variant: "task"` (Тон: `blue` / `indigo`, Икона: `fas fa-list-check`)
  - `variant: "exercise"` (Тон: `green`, Икона: `fas fa-dumbbell`)
  - `variant: "discussion"` (Тон: `purple`, Икона: `fas fa-comments`)
* **JSON схема:**
```json
{
  "type": "tag",
  "id": "tag-task-1",
  "icon": "fas fa-list-check",
  "text": "Задача 1: Социални мрежи",
  "modalTarget": "modalSocialTask",
  "tone": "blue",
  "variant": "task",
  "skipNav": true
}
```

---

### 23. `accordion` (Многостепенен акордеон)
* **Предназначение:** Основният гръбнак на урока. Съдържа точките от учебния план с възможност за самостоятелно разгъване/свиване, икони и цветови акценти.
* **Параметри в `options`:**
  - `itemsAlign`: `"stretch"`
  - `titleAlign`: `"left"`
  - `singleOpen`: `false` (позволява едновременно отваряне на няколко точки)
  - `startClosed`: `false` (първият елемент е отворен по подразбиране)
* **JSON схема:**
```json
{
  "type": "accordion",
  "id": "main-lesson-accordion",
  "items": [
    {
      "id": "section-1",
      "title": "1. Социални мрежи и критичен анализ",
      "content": [ ... ]
    }
  ]
}
```

---

### 24. `subsection` (Тематична подсекция)
* **Предназначение:** Подточка вътре в елемент на акордеона, обединяваща тематично свързани теоретични блокове, изображения и упражнения.
* **JSON схема:**
```json
{
  "type": "subsection",
  "id": "subsection-cloud-rights",
  "heading": "Нива на достъп и права в споделен документ",
  "content": [
    {
      "type": "text",
      "id": "text-rights-desc",
      "content": "В облачните платформи (Google Drive, OneDrive) съществуват три основни нива на права: **Viewer** (преглед), **Commenter** (коментар) и **Editor** (редактиране)."
    }
  ]
}
```
