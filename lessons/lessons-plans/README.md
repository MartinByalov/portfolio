# Педагогически планове на уроците

Плановете са групирани по курс/клас, а не се съхраняват в една обща директория:

```text
lessons/lessons-plans/
├── it-8/
├── it-9/
├── it-10/
└── kaos-12/
```

## Именуване

Използва се формат:

```text
<course-id>-<заглавие на урока>.md
```

Пример:

```text
it-8-Съвременни компютърни системи.md
```

Планът се създава преди JSON имплементацията и описва учебните цели, съдържателните ядра, педагогическия ход, медиите, placeholders, интеракциите и оценяването.
