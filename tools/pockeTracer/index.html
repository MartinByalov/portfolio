🔰 Йерархия на режимите (Command Modes) и навигация
enable User >
Преминаване от потребителски към привилегирован режим (EXEC mode).
configure terminal (conf t) Priv #
Влизане в глобален конфигурационен режим на устройството.
exit Всички
Връщане с едно йерархично ниво назад.
end (или Ctrl+Z) (config*)#
Директно излизане до привилегирован режим (Router#).
hostname <име> (config)#
Задава име на устройството (напр. hostname R1_Sofia).
write memory (wr) Priv #
Запазва текущата конфигурация (running-config) в постоянната памет NVRAM.
🔌 Конфигуриране на интерфейси и IP адреси
interface <тип/номер> (config)#
Влизане в режим на интерфейс (напр. int Gi0/0, int Fa0/1, int Vlan10).
interface range <порт-порт> (config)#
Едновременна конфигурация на група портове (напр. int range Fa0/1-24).
ip address <ip> <маска> (config-if)#
Задаване на IPv4 адрес и маска (напр. ip address 192.168.1.1 255.255.255.0).
no shutdown (config-if)#
Активиране / пускане на интерфейса (състояние UP).
shutdown (config-if)#
Административно спиране / изключване на порта.
description <текст> (config-if)#
Добавя пояснително описание на интерфейса (напр. description Link_to_Core).
ip default-gateway <ip> (config)#
Задава шлюз по подразбиране за управление на L2 суич.
⚡ VLAN мрежи, Access & Trunk портове (Суичинг)
vlan <id> (config)#
Създава виртуален LAN сегмент (напр. vlan 10).
name <име> (config-vlan)#
Задава име на създадения VLAN (напр. name Teachers).
switchport mode access (config-if)#
Настройва порта в режим Access за крайно устройство (PC, принтер, камера).
switchport access vlan <id> (config-if)#
Присвоява порта към посочения VLAN (напр. switchport access vlan 20).
switchport mode trunk (config-if)#
Превръща порта в Trunk канал (пренася маркиран трафик за множество VLAN-и).
switchport trunk allowed vlan <списък> (config-if)#
Ограничава кои VLAN-и могат да преминават през транка (напр. 10,20,30 или all).
switchport trunk encapsulation dot1q (config-if)#
Задава стандартизирано 802.1Q маркиране на транк порта (при L3 суич 3560).
no switchport (config-if)#
Премахва L2 суич функционалността и прави порта L3 рутиращ порт (L3 Switch).
spanning-tree portfast (config-if)#
Пропуска състоянията на Spanning Tree за незабавно преминаване към forwarding.
🌐 IP Маршрутизация (Routing), Статични маршрути и NAT
ip routing (config)#
Активира IP маршрутизирането на L3 устройство (за Switch 3560-24PS).
ip route <мрежа> <маска> <next-hop> (config)#
Добавя статичен маршрут (напр. ip route 192.168.20.0 255.255.255.0 10.0.0.2).
ip route 0.0.0.0 0.0.0.0 <gateway> (config)#
Default Route (Маршрут по подразбиране към интернет или upstream рутер).
no ip route <мрежа> <маска> (config)#
Премахва дефиниран статичен маршрут.
ip nat inside / ip nat outside (config-if)#
Обозначава интерфейса съответно като вътрешен (LAN) или външен (WAN/ISP) за NAT.
access-list <1-99> permit <мрежа> <wildcard> (config)#
Дефинира списък с разрешени локални адреси (напр. access-list 1 permit 192.168.0.0 0.0.255.255).
ip nat inside source list <acl> interface <if> overload (config)#
Активира PAT (Port Address Translation / NAT Overload) през посочения външен интерфейс.
📡 DHCP Сървър (Автоматично конфигуриране на IP адреси)
ip dhcp excluded-address <от> [<до>] (config)#
Изключва статично заети адреси от раздаване (напр. ip dhcp excluded 192.168.10.1 192.168.10.10).
ip dhcp pool <име> (config)#
Създава нов DHCP пул и влиза в подрежим (dhcp-config)#.
network <мрежа> <маска> (dhcp-config)#
Задава адресния диапазон на мрежата за раздаване (напр. network 192.168.10.0 255.255.255.0).
default-router <ip> (dhcp-config)#
Задава адрес на шлюза по подразбиране (Default Gateway) за DHCP клиентите.
dns-server <ip> (dhcp-config)#
Задава DNS сървър (напр. dns-server 8.8.8.8).
🔍 Диагностика, проверка и мониторинг (Show & Test)
show ip interface brief (sh ip int br) Priv #
Обобщен преглед на всички портове: техните IP адреси, статус (UP/DOWN) и протокол.
show running-config (sh run) Priv #
Показва цялостната активна конфигурация в RAM паметта на устройството.
show ip route Priv #
Извежда пълната маршрутизираща таблица (Connected 'C', Static 'S', Default '*').
show vlan (sh vlan) Priv #
Показва всички активни VLAN-и и портовете, асоциирани с тях.
show arp Priv #
Извежда ARP кеша (съответствие между IP и MAC адресите на съседните устройства).
show interfaces [<порт>] Priv #
Детайлна статистика и хардуерен MAC адрес за конкретен или всички интерфейси.
ping <ip> Всички
Изпраща 4 ICMP ехо-пакета за тестване на мрежова свързаност (с време на отговор).
traceroute <ip> (tracert) Всички
Трасира междинните рутери (хопове) по пътя до целевия IP адрес.
💻 PockeTracer и команди за крайни устройства (PC / Laptop / Server)
connect <име_устройство> PockeTracer>
Отваря конзолна CLI сесия към посоченото устройство (напр. connect Router_Core).
disconnect Всяко у-во
Затваря текущата конзолна сесия и се връща в PockeTracer>.
show devices PockeTracer>
Показва списък на всички разположени устройства, техния статус и конфигурирани IP-та.
show connections PockeTracer>
Извежда всички прокарани кабели и връзки между устройствата.
show topology PockeTracer>
Автоматично разпознава типа на топологията (Star, Bus, Ring, Mesh, Tree).
ipconfig PC / Server
Показва IPv4 адреса, подмрежовата маска и шлюза по подразбиране на компютъра.
clear Всички
Изчиства съдържанието на конзолния екран.
Tab / ↑ ↓ Клавиатура
Tab за автоматично дописване на командата, стрелки нагоре/надолу за история.
