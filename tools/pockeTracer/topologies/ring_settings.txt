║ Ring Topology — Настройки                        ║
╚══════════════════════════════════════════════════╝

Описание:
- Token Ring стил: централно устройство MAU затваря кръга вътрешно.
- Всеки PC има един Ring (Coax) порт; връзки PC ↔ MAU (Coaxial).
- Локален L2 сегмент; няма Gateway.

Адресиране:
- Мрежа: 192.168.60.0/24, Маска: 255.255.255.0
- PC адреси: .11–.16

Свързване:
- Постави Token Ring MAU в центъра.
- Свържи всеки PC (Coax NIC) към свободен MAU порт с Coaxial кабел.

Конфигурация (за всеки PC):
connect Ring_PC_XX
enable
configure terminal
ip address 192.168.60.X 255.255.255.0
dns-server 8.8.8.8
end
ipconfig

Проверки:
- ping между PCs (например PC_01 → PC_02)
- show connections — връзките са “coaxial” PC ↔ MAU
